Procedural Animation

Experimentation with procedural animation and active ragdolls.

  • Unity Animation Rigging
  • IK
  • Active ragdoll

As a programmer, I wanted a solution for animating my games without actually doing animations, and that's when I stumbled upon procedural animation. So what is procedural animation?

“A procedural animation is a type of computer animation, used to automatically generate animation in real-time to allow for a more diverse series of actions than could otherwise be created using predefined animations”, or so says Wikipedia.

So I used Unity's new Animation Rigging as an IK solution, and wrote my own for the head.

I then added a leg home position, wrote a custom parenting script to fix some problems with rotation, and added stepping logic. After adding some scripts for body rotation and foot placement on different heights, this is what I got.

Active ragdoll

After some more playing around, I added an active ragdoll!

I'm not sure this is the way it's traditionally done, but what I ended up doing is running 2 models: one running the IK and walking around, and one with a ragdoll, plus a script that makes the ragdoll match the IK model.
