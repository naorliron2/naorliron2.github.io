Reactive Floor

A reactive floor shader using vertex displacement.

  • Shader
  • Vertex displacement
  • With Tomer Steinbock

As a challenge from one of our teachers, my colleague and friend Tomer Steinbock and I started working on a “Reactive Floor” shader.

At first we managed to get the effect we wanted in code by instantiating particles and telling them how to behave, but we soon realized this was pretty heavy and couldn't be scaled up or really used in a game.

So we decided to try and write a shader. We had played around with some simple shaders for toon shading, but this was our first time playing with vertex displacement.

Color can be controlled in the material.

We were both pretty happy with the result. We also wanted to add some waves with Perlin noise and some different effects, but we had other, more important projects to work on.
