Weeb Simulator

A crafting game where a “shut-in” weeaboo learns the fun of crafting.

  • Third college project
  • Unity HDRP
  • No third-party assets

Our third project for college had a special twist: we needed to make a game using no third-party programs, so I decided to use the “best” Unity has to offer by going with the High Definition Render Pipeline.

Gameplay

So what exactly is the gameplay of Weeb Simulator? The goal is to find all the crafting recipes using the crafting table in your room.

Left-clicking an item picks it up, and left-clicking again while holding an item places it back down. Using the crafting table, you can craft an assortment of items.

Posters can also be placed on walls for some customization.

Most objects in the world have Rigidbodies and can be interacted with.
